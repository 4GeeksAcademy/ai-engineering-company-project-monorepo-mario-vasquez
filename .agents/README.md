# Regla de desarrollo

## Alcance de aplicacion

**Siempre activa:** se aplica a todo agente que realice tareas de desarrollo en cualquier carpeta de este repositorio, independientemente del lenguaje o tipo de archivo.

## Regla

Antes de cambiar codigo, identifica la carpeta responsable y consulta su `README.md` local. Tras el cambio, ejecuta la comprobacion automatizada mas cercana al comportamiento modificado; si no existe una comprobacion aplicable, indica esa limitacion y el riesgo que deja sin verificar.
