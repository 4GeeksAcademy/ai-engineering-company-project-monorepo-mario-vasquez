# SLA del proceso de selección

Plazos de entrega comprometidos por tipo de búsqueda:

- Perfil ejecutivo (C-level, VP): promedio de 8 semanas, con una lista corta de 3 candidatos.
- Perfil gerencial (director, manager): promedio de 6 semanas, con una lista corta de 3 a 4 candidatos.
- Perfil técnico especializado: promedio de 5 semanas, con una lista corta de 3 candidatos.

Estos plazos son promedios basados en búsquedas anteriores exitosas, no una garantía contractual estricta, salvo que el contrato lo especifique explícitamente.

Si, transcurridas 4 semanas de una búsqueda ejecutiva, no se ha presentado ningún candidato calificado, el consultor asignado debe escalar el caso a Javier Almeida (gerente de Operaciones) y notificar proactivamente al cliente con un plan de acción.

Nexova no garantiza plazos de entrega para búsquedas con requisitos geográficos muy restrictivos (por ejemplo, un único candidato disponible en una ciudad específica).
